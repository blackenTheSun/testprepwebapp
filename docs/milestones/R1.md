- scoring for all four item types, including matching's partial and per-pair results

- immediate vs end feedback
- the recall flow (submit is ignored; only reveal → mark)
- expiry at exactly `displaySeconds`, the Show answer and Next card paths, and late submission counting as expired
- standard sets ignoring timers
- summary grouping
- retry order and contents (misses + unanswered + Review) and "no retry when all correct"
- session start / retry / close / last score
