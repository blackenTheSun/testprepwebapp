## Validation rules implemented

Schema (Ajv, compiled at build time) → `UniqueIdRule` → `FormulaExpressionRule` → `ReferenceRule` → `BindingRule` → `GivenValueRule` → (if no errors) `AuthoredValueRule`. See [docs/TEST_FILE_GUIDE.md §7](../TEST_FILE_GUIDE.md) for the author-facing list.
